隐私政策

照片和影片

选中的照片与生成的影片都在浏览器里处理，文件不上传服务器。点击保存后，影片写入你选择的设备下载位置。刷新或关闭页面会清除当前装片状态。

Cookie、广告与统计

小样代码不设置 Cookie，也未接入 Google AdSense、第三方广告或分析工具。小样不收集访问统计，因此没有站点统计数据留存。Google 广告偏好可在 Google 广告设置管理。

托管与反馈

GitHub Pages 为安全目的记录访问者的 IP 地址。GitHub 托管和反馈服务的数据处理、Cookie 与留存请见 GitHub 隐私声明及 GitHub Pages 说明。
